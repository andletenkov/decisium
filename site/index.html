Gherkin · Playwright · AI agent

From behavioral specification to intelligent execution.

Write plain-English Gherkin steps. Decisium drives a real browser to carry them out, records what each Step resolved to, and replays it in CI without calling the model.

Get started Cookbook 
$ npm install --save-dev decisium
$ npx playwright install chromium
$ npx decisium run checkout.feature
No selectors

Steps in plain English

“When I schedule the campaign”. The agent finds the element by meaning, not by CSS.

Record / replay

Cassettes

Each resolution is saved next to the feature. --record none replays with zero model calls.

Agent-ready

Failure reports

A failed run writes report.md with the decision trail, page text and a rerun command for a coding agent.
